# 📊 Supply Chain Dashboard (Microsoft Excel)

## 📌 Project Overview

The Supply Chain Dashboard is an interactive Excel data analytics project designed to analyze sales, profitability, order volume, customer segments, regional performance, shipping modes, and delivery performance.

The project uses data cleaning, Excel formulas, PivotTables, PivotCharts, slicers, and KPI cards to transform raw supply chain data into an interactive business dashboard.

## 🎯 Objectives

- Clean and standardize the raw supply chain data.
- Organize the data into an analysis-ready format.
- Create PivotTables for different business metrics.
- Build interactive PivotCharts for visual analysis.
- Track important business and operational KPIs.
- Analyze sales and profitability across regions.
- Analyze order quantity and customer segments.
- Evaluate delivery and shipping performance.
- Provide an easy-to-use dashboard for business analysis.

## 📊 Dashboard Features

- Interactive Customer Segment filter
- Interactive Market filter
- Interactive Year filter
- Interactive Shipping Mode filter
- Sales analysis by region
- Profit analysis by region
- Order quantity analysis by region
- Yearly/monthly sales trend
- Order status analysis
- Delivery status analysis
- Shipping mode analysis
- Customer segment analysis
- KPI cards for quick performance monitoring

## 📈 Key Performance Indicators (KPI)

| KPI | Description |
|---|---|
| **Total Sales** | Total sales/revenue generated from orders |
| **Total Profit** | Total profit generated |
| **Total Orders** | Total number of orders |
| **Average Order Value** | Average sales value per order |
| **Late Delivery %** | Percentage of orders classified as late |

### Excel Workbook Sheets

```text
Original
   ↓
Cleaned
   ↓
Pivot
   ↓
Dashboard
```

* **Original** -- Contains the original/raw dataset.
* **Cleaned** -- Contains the cleaned and formatted data used for analysis.
* **Pivot** -- Contains PivotTables created for the dashboard.
* **Dashboard** -- Contains the final interactive dashboard.



## ▶️ How to Use

1. Download or clone this repository.
2. Open **Supply Chain Dataset.xlsx** using Microsoft Excel.
3. Go to the **Dashboard** sheet.
4. Use the slicers on the left side to filter the dashboard by:

   * Customer Segment
   * Market
   * Year
   * Shipping Mode
5. Review the KPI cards and charts.
6. Use the **Pivot** sheet to inspect the underlying PivotTables.
7. If the source data is modified, refresh the PivotTables/PivotCharts to update the dashboard.
