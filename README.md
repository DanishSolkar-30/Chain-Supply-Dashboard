📊 Supply Chain Dashboard (Microsoft Excel)
📌 Project Overview

The Supply Chain Dashboard is an interactive Excel data analyticsproject designed to analyze sales, profitability, order volume, customersegments, regional performance, shipping modes, and deliveryperformance.

The project uses data cleaning, Excel formulas, PivotTables,PivotCharts, slicers, and KPI cards to transform raw supply chain datainto an interactive business dashboard.

🎯 Objectives

Clean and standardize the raw supply chain data.

Organize the data into an analysis-ready format.

Create PivotTables for different business metrics.

Build interactive PivotCharts for visual analysis.

Track important business and operational KPIs.

Analyze sales and profitability across regions.

Analyze order quantity and customer segments.

Evaluate delivery and shipping performance.

Provide an easy-to-use dashboard for business analysis.

▶️ How to Use

Download or clone this repository.

Open Supply Chain Dashboard.xlsx using Microsoft Excel.

Go to the Dashboard sheet.

Use the slicers on the left side to filter the dashboard by:

Customer Segment

Market

Year

Shipping Mode

Review the KPI cards and charts.

Use the Pivot sheet to inspect the underlying PivotTables.

If the source data is modified, refresh the PivotTables/PivotChartsto update the dashboard.

Recommended Excel Version

Use a recent version of Microsoft Excel for the best compatibilitywith PivotTables, PivotCharts, and slicers.
